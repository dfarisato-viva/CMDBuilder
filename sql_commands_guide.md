# Comandi SQL Server corretti per VS Code

## Comandi disponibili nell'estensione ms-mssql.mssql:

### Connessione Database
- `MS SQL: Connect` - Connetti a SQL Server
- `MS SQL: Disconnect` - Disconnetti da SQL Server
- `MS SQL: Manage Connection Profiles` - Gestisci profili di connessione

### Query e Esecuzione
- `MS SQL: New Query` - Crea nuova query
- `MS SQL: Execute Query` - Esegui query corrente
- `MS SQL: Cancel Query` - Annulla query in esecuzione

### Object Explorer (Nuovo)
- `MS SQL: Add Connection` - Aggiungi connessione (sostituisce addObjectExplorer)
- `MS SQL: Refresh` - Aggiorna Object Explorer
- `MS SQL: Remove Connection` - Rimuovi connessione

### Utilità
- `MS SQL: Choose Database` - Seleziona database
- `MS SQL: List Databases` - Elenca database disponibili
- `MS SQL: Show Query History` - Mostra cronologia query

## Come accedere all'Object Explorer:

1. Premi Ctrl+Shift+P
2. Digita: "MS SQL: Add Connection" (NON addObjectExplorer)
3. Configura la connessione
4. L'Object Explorer apparirà automaticamente nella sidebar
